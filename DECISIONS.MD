# Decision Points

## DP1 — Booking Rejection
A creator can decline an incoming booking request. When declined, the client sees the booking status as "Declined" and can request the gig again.

## DP2 — Double Booking
A gig cannot receive another booking while it already has a pending booking. This prevents multiple clients from booking the same gig at the same time.

## DP3 — Discovery Order
Newly posted gigs appear at the top of the marketplace. This makes the latest opportunities visible first.
