# SkillSwap

SkillSwap is a creator gig marketplace where users can post, discover, and book gigs.

## Features

- Post a gig
- Browse and search gigs
- Book a gig
- Creator dashboard
- Accept or decline bookings
- Prevent double booking
- Newest gigs appear first

## API Usage

No standard external API was used. The project is a frontend prototype using JavaScript.
